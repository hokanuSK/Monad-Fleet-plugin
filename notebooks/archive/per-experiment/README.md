# Per-experiment notebook forks (archived)

These are snapshots of `01_measurement_5ghz_ble_power_analysis.ipynb` and
`02_wifi_ap_inventory.ipynb`, each rebuilt for a specific experiment ID
(exp145, exp153, exp156, exp158, exp174).

should be used for new experiments; load the desired pcap/run-summary set
via the parameter cells.

Kept for traceability of how each experiment was analysed at the time.
