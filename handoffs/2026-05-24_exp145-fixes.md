# Session Handoff — 2026-05-23/24

## What was broken and what was fixed

### 1. Exp 145 — HTTP 413 blocking PCAP uploads to eLab
**Root cause**: eLab nginx had `client_max_body_size 100M` and PHP had `upload_max_filesize=100M` / `post_max_size=100M`. PCAPs are ~190-200MB.

**Fixes (persistent, in git)**:
- `infrastructure/aws/nginx-uploads.conf` — sets `client_max_body_size 500M`
- `infrastructure/aws/php-fleet-uploads.ini` — sets `upload_max_filesize = 500M`, `post_max_size = 500M`
- `infrastructure/aws/docker-compose.aws.yml` — volume-mounts both files into the `web` container

Applied on EC2 deploy dir at `/home/ladamik/FleetManager_deploy/` and hot-patched the running container (nginx reloaded, PHP-FPM restarted via s6).

---

### 2. Artifact upload ordering bug — run-summary.json sent before PCAP
**Root cause**: `upload_report_artifacts_to_elab` in `src/device-sim/agent_v2/sinks.py` iterated `report.artifacts` in protobuf default order. If run-summary.json came before the PCAP, fleet service triggered `finalize_server_spooled_run` while the PCAP was still mid-stream → premature finalize with no PCAP in spool.

**Fix (committed)**: Sort `report.artifacts` so `run-summary.json` always uploads last:
```python
artifacts = sorted(
    report.artifacts,
    key=lambda a: 1 if Path(normalize(a.name) or "").name == "run-summary.json" else 0,
)
```
Deployed to all 5 Pis; agents restarted.

**Loss**: monad-02's PCAP from exp 145 is permanently lost (ordering bug + early finalize).

### 4. "WireGuard drops" during exp 145 upload window — actually clean reboots
**Root cause**: Ubuntu's `unattended-upgrades` ran automatic package updates and triggered auto-reboot on monad-02 (10:29 UTC) and monad-04 (10:21 UTC) during the 08:00-09:00 UTC upload window.

Confirmed via `journalctl -b -1`: both had orderly systemd shutdowns, NOT crashes or WireGuard failures.

**Fix**: Applied to all 5 Pis (10.200.0.11–15):
```
/etc/apt/apt.conf.d/99no-reboot:
  Unattended-Upgrade::Automatic-Reboot "false";
```
All 5 Pis confirmed written (see above).
